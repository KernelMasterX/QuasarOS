# QuasarOS-project 🌌
### Light the Galaxy

> An Android 13 GSI Project - Minimal, Fast, Cyan.

QuasarOS is a custom Generic System Image (GSI) based on Ponces AOSP 13, designed to light up your device with a clean Cyan universe.

**Status: First Build - 3 Variants**

---

### ✨ Variants

| Variant | File | Description |
| :--- | :--- | :--- |
| **arm64_bvN** | `system-arm64_bvN.img.xz` | Vanilla - Clean, No GApps, No SU |
| **arm64_bgN** | `system-arm64_bgN.img.xz` | GApps - Full Google Apps, No SU |
| **arm64_bgN-core** | `system-arm64_bgN-core.img.xz` | Core - Lite GApps, No SU |

> All variants are `A/B` and `No-Superuser` for better security & banking apps.
